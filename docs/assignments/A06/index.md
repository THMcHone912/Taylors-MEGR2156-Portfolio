The objective of this assignment was to continue the bracket design developed during the previous assignment by converting the analytically determined dimensions into a parametric SolidWorks model and creating a complete multi-view engineering drawing.

The bracket was originally designed to support a polyester strap while attaching to a rigid T-beam. The previous analysis established the required dimensions based on the applied loading, bending stress, stiffness, material properties, safety factor, and maximum allowable deflection. The second objective was to create an engineering drawing that clearly communicates the geometry, dimensions, tolerances, fit requirements, and design intent of the bracket. The drawing was created using third-angle projection and includes the required general tolerance block.

The final goal was to document the design process, including CAD development, parameter selection, mistakes, corrections, engineering decisions, and lessons learned.

## Decision of the Bracket Design
The bracket was modeled in SolidWorks using a series of sketches and features whose dimensions were controlled by parameters.

Instead of treating every dimension as an independent number, the model was organized so that important dimensions could be modified while maintaining the intended relationships between features.

The main parameters included dimensions associated with:

Overall bracket geometry
T-beam interface
Sliding-fit gaps
Strap interface
Feature thicknesses
Overall height/width
Hole or pin locations
Structural features determined from the previous analysis

A parametric table was created to show the dimensions controlling the model.

Example parameter organization
Parameter	Purpose
Overall Width	Controls overall bracket width
Overall Height	Controls bracket height
Feature Thickness	Controls structural thickness
T-Beam Gap	Controls sliding fit
Strap Opening	Controls polyester strap interface
Hole/Pin Diameter	Controls functional connection
Feature Length	Controls the dimension established by the previous analysis

Analytical Dimension Driving the CAD Model

One of the most important parts of this assignment was connecting the previous engineering analysis directly to the CAD model.

The governing stiffness or strength equation from the previous assignment was used to determine a critical bracket dimension rather than selecting the dimension arbitrarily.

For a rectangular section:

I=bh^3/12

The resulting dimension was then incorporated into the SolidWorks model as a parametric dimension/equation, rather than simply typing the calculated number into the sketch. These calculations, like all others, can be seen from last week's assignment.

The dimension was controlled through the SolidWorks parametric system using the governing analytical relationship from the previous assignment. This allowed the calculated design requirement to become part of the CAD model rather than remaining an independent calculation outside of the model. If the governing input parameter is changed, the dependent dimension can update automatically and maintain the intended design relationship.

## Why I Chose This Design

The final bracket geometry was selected because it provides a practical balance between structural requirements, manufacturability, assembly, and dimensional control. The previous analysis established the required structural dimensions, while the CAD stage allowed those dimensions to be incorporated into a complete part. The design also needed to interface with the rigid T-beam. Because the bracket uses three sliding-fit interfaces, the geometry of these regions was treated as functional rather than simply cosmetic.

The design then separates dimensions into two categories:

Functional dimensions and non-critical dimensions.

Functional dimensions show how the bracket interacts with another component.

Examples include: T-beam sliding gaps, Mating surfaces, Pin/hole interfaces, and Strap opening dimensions

Functional dimensions require more careful tolerancing because an error can affect assembly or operation.

Non-critical dimensions describe portions of the bracket where small dimensional variations have little effect on function.

Examples can include: General outside lengths, Non-mating exterior features, and general thicknesses where the exact value does not control assembly

Non-critical dimensions can use the appropriate general tolerance rather than unnecessarily tight tolerances.


## Communicate

The hardest things from this assignment was maintaining the T-beam fit because manufacturing variations exist. Tolerancing also was a big challenge here because during the drawing portion I leanred that tighter is not automatically better.

The tolerance needs to communicate the function of the dimension. A sliding-fit dimension requires tighter control because it directly affects assembly, while a non-critical exterior dimension can generally use a looser tolerance. This required thinking about the function of each dimension, rather than applying the same tolerance to everything.
